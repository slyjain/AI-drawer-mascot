# AI Learning Space - Feature Tracking

## Core Goal
Create an AI learning space that teaches content to complete understanding.

## Required Features
- [ ] **AI Mascot**: A mascot that interacts and teaches the content.
- [ ] **Voice Interaction**: The mascot can listen to the user.
- [ ] **Screen Drawing**: The mascot can draw on the screen to explain concepts.
- [ ] **Interactive Quizzes**: The system can present interactive quizzes with questions.
- [ ] **Mastery Learning**: The AI will continuously teach the user until they have complete understanding of the topic/project.

## Tech Stack
- Frontend: React
- Backend: Java
