# AI Learning Space

An interactive AI-powered learning environment designed to teach users topics through an engaging, multi-modal interface. 

## Features
*   **Interactive Mascot:** A virtual teacher that guides you through the content.
*   **Voice Enabled:** Speak directly to the AI for a natural learning experience.
*   **Visual Learning:** The AI can draw on the screen to illustrate complex concepts.
*   **Built-in Quizzes:** Tests your knowledge interactively to ensure comprehension.
*   **Adaptive Pacing:** The system will not move on until complete understanding is achieved.

## Technologies
*   Java
*   React
